连接 GitHub 仓库

只需要设置一次。token 只保存在这台设备的浏览器里，不会写进网页代码。

没有 token？看这里生成一个（只给这个仓库）
  1. 打开 GitHub Fine-grained tokens，点 Generate new token。
  2. Token name 随便填，比如 album-admin；Expiration 选 90 天。
  3. Repository access 选 Only select repositories，只勾选 littlestar。
  4. Repository permissions 里把 Contents 设成 Read and write。
  5. 点 Generate token，复制生成的 token 粘贴到上面。

如果想让宝宝也能加照片，可以再生成一个同样的 token 只给她用，丢了随时删掉。

仓库设置（一般不用改）

提醒：token 相当于这个仓库的钥匙。别把它写进网站代码、别发到公开群里；如果泄露，去 GitHub 删除这个 token 即可。
